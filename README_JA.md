## コア機能

- **オーケストレーター インテリジェントディスパッチ** — あなたの指示を受け取り、意図を理解し、複雑度を評価し、タスクを並列サブタスクに分解し、最適なサブエージェントに動的に割り当てます
- **Plan インスタントプランニング** — 要件を分析し、完全な実行計画（手順、ツール選択、推定時間）を出力します。手動で確認後、Agent または Orchestrator モードに切り替えて実行します
- **Agent 並列実行** — 複数のサブエージェントが同時に作業し、各部分を担当、自動的にエラーを修正し、協調し、結果を統合して完全な成果物として納品します
- **進化するスキル** — カスタムスキルを一言で作成または改良します。一度教えれば、永久に再利用可能。チームが使えば使うほど、あなたのことをより理解するようになります
- **MCP エコシステム統合** — データベース、Figma、Slack、GitHub などの外部ツールとシームレスに連携
- **デスクトップネイティブ体験** — ローカルファイルシステムへの直接読み書き、開発環境との深い統合

## インストールと起動

### システム要件

| OS | 最低バージョン | アーキテクチャ | 推奨スペック |
|----|-----------------|--------------|-------------|
| macOS | 12 (Monterey)+ | Apple Silicon / Intel | 8 GB RAM、2 GB ディスク容量 |
| Windows | Windows 10+ | x64 / ARM64 | 8 GB RAM、2 GB ディスク容量 |

### ダウンロードとインストール

**方法1：公式ウェブサイト（推奨）**

1. [www.doforu.ai/ja](https://www.doforu.ai/ja) にアクセス
2. 「今すぐダウンロード」をクリックし、お使いのシステムバージョンを選択
3. インストールしてアプリを起動

**方法2：GitHub Releases**

1. [Releases ページ](https://github.com/yctech2026/Doforu-APP/releases) にアクセス
2. 最新パッケージをダウンロード：
   - macOS：`Doforu-3.5.0-universal.dmg`
   - Windows：`Doforu-3.5.0-x64.exe`
3. インストーラーを実行

### 初回起動

1. **macOS**：`.dmg` を開き、Doforu をアプリケーションフォルダにドラッグ。初回起動時は **システム設定 → プライバシーとセキュリティ** で許可してください。
2. **Windows**：インストーラーを実行し、ウィザードに従ってください。ファイアウォールの警告が表示されたら、ネットワークアクセスを許可してください（モデルプロバイダーの API に直接接続するために使用します）。
3. 初回起動時、お好みのモデルを選択し API キーを入力し、画面の指示に従って初期設定を完了してください。

## クイックスタート

インストール後、メインインターフェースの入力ボックスにタスクを自然言語で記述してください：

> 「ログイン機能、React + TypeScript、ダークモード対応の Todo アプリを作成して」

### ステップ1：実行モードを選択

ニーズに応じて実行方法を選択してください：

| モード | 最適な用途 | 説明 |
|------|----------|-------------|
| **Plan** | まず計画を確認したい場合 | 要件を分析し、完全な実行計画（手順、ツール選択、推定時間）を出力します。確認後に実行 |
| **Agent** | シンプルなタスク、クイック実行 | 単一のエージェントで直接実行。コピーライティング、コードスニペット、簡単な問い合わせに最適 |
| **Orchestrator** | 複雑なタスク、マルチエージェント協調 | メインエージェントが自動でタスクを分解し、複数のサブエージェントを並列実行。フルスタック開発、リファクタリング、深層分析、マルチファイル協調に最適 |

> 💡 どれを選べばいいかわからない？ とにかく **Orchestrator** を使ってください。自動で複雑度を評価します：軽量タスクは `fast` サブエージェントへ、深いタスクは `extreme` サブエージェントへ — 手動選択は不要です。

### ステップ2：実行を監視

会話ストリームに実行の全容がリアルタイムで表示されます：
- **AI レスポンスストリーム** — 思考過程と結果を逐次出力
- **ツールコールカード** — 各ツール（ファイル読み取り、コード書き込み、コマンド実行、サブエージェント呼び出しなど）がカードで表示され、クリックでパラメータと戻り値を確認可能
- **ステータスインジケーター** — 下部ステータスバーに現在のモード（Agent / Plan / Orchestrator 実行中...）を表示
- **いつでも中断** — 下部の「停止」ボタンをクリックして、現在のタスクを即座に終了

### ステップ3：確認と反復

タスク完了後、結果は会話ストリームに完全に表示されます：
- **出力サマリー** — AI が自動で成果物と主要な結論を集約
- **ファイル変更** — ファイル書き込み/編集操作は変更行のサマリー（+N −M）を表示
- **スクリーンショット保存** — AI の応答にホバーし、右下のボタンをクリックしてその返信を PNG として保存
- **反復を継続** — 下部の入力ボックスから新しい指示を直接送信して現在のコンテキストに基づいて改善するか、新しいタスクを開始
